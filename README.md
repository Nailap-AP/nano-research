Aplikasi web modern untuk analisis penelitian dengan UI yang menarik dan fitur lengkap. Deploy dengan mudah di Streamlit Cloud!

## ✨ Fitur Utama

### 📝 Generator Resume Penelitian
- **Template profesional** dengan berbagai gaya
- **Export ke PDF** dengan layout otomatis
- **Form step-by-step** dengan validasi
- **Auto-save** progress penelitian

### 📈 Analisis Kurva Kalibrasi
- **Regresi linear lengkap** dengan statistik
- **Visualisasi interaktif** menggunakan Plotly
- **Multiple input methods**: manual, CSV, Excel, sample data
- **Advanced features**: confidence interval, residual analysis

### 🎨 UI Premium
- **Dark theme** dengan gradient colors
- **Animasi Lottie** untuk pengalaman menarik
- **Responsive design** untuk semua device
- **Progress tracking** dengan visual feedback

## 🚀 Cara Deploy

### Deploy di Streamlit Cloud (Mudah)
1. **Fork repository** ini ke GitHub Anda
2. **Buka** [share.streamlit.io](https://share.streamlit.io)
3. **Login** dengan akun GitHub
4. **Klik "New app"**
5. **Pilih repository** dan branch
6. **Set Main file path** ke `app.py`
7. **Klik "Deploy"** - Selesai! 🎉

### Deploy Lokal
```bash
# Clone repository
git clone https://github.com/username/labmate-pro.git
cd labmate-pro

# Install dependencies
pip install -r requirements.txt

# Run aplikasi
streamlit run app.py
